# WholeLottaVinyl Record Grading Helper

Free static tool: tick what you see on the vinyl and cover, get a WholeLottaVinyl grade (**M · NM · EX · VG+ · VG · G+**) and a paste-ready `Graded: EX/VG` listing line.

**Live:** https://frozenvisions.github.io/wlv-grading-helper/

## Local

Open `index.html` via a local static server, or:

```bash
npx --yes serve -l 4173 .
```

## Unpublish

- Disable Pages: GitHub → this repo → **Settings → Pages →** set Source to **None**, or  
- Delete the repository (Settings → Danger Zone).

No backend, no accounts, no customer data. Guide only.
